# Расстояния от Иркутска

Справочник хранится в `src/data/cityDistances.json`: 88 городов России,
включая крупные города, региональные центры и ближайшие к Иркутску города.
Для каждого города сохранены название, варианты написания, приблизительные
координаты центра и готовое значение `distanceKm`.

Координаты центров составлены локально и имеют приблизительную точность.
Внешняя сверка справочника GeoNames в этой сессии была недоступна.
Данные не следует использовать для навигации.

Расстояния рассчитаны по формуле гаверсинусов на сфере радиусом 6371,0088 км.
Начальная точка — центр Иркутска: 52,2869° с. ш., 104,3050° в. д.
Результат округлён до ближайших 10 км и затем сохранён в JSON.
Это расстояние по поверхности Земли по прямой между центрами городов,
а не автомобильный или железнодорожный маршрут.

Примеры: Москва — около 4200 км, Санкт-Петербург — около 4420 км,
Новосибирск — около 1430 км, Томск — около 1330 км.
Иркутск имеет значение 0, но пользователь видит отдельный ответ:
«Доктор уже в Иркутске». Для неизвестного города число не подставляется.

Сопоставление учитывает регистр, «ё/е», пробелы, разновидности дефиса,
префиксы «г.» и «город», сохранённые сокращения и английские названия.
Поддерживаются адреса, где город выделен запятыми. Части слова и
неоднозначный ввод с несколькими известными городами не сопоставляются.

Для добавления города внесите запись с корректными координатами и вариантами
названия, затем выполните `node scripts/update-city-distances.mjs`.
Смена шуточной реплики не меняет сохранённое расстояние.
